# NOIR® — Independent Creative Studio

A responsive, editorial-style concept website for a fictional independent creative studio, built with HTML5, CSS3, vanilla JavaScript, and [Lenis](https://github.com/darkroomengineering/lenis) for smooth scrolling.

The project explores contemporary editorial design, oversized typography, asymmetrical layouts, cinematic imagery, and subtle interactions.

 **Live Website:** [View NOIR® Live](https://noir-creative-studio-beta.vercel.app)

##  Features

* **Editorial design:** Dark aesthetic, oversized typography, and electric-lime accents.
* **Responsive layout:** Designed for desktop, tablet, and mobile screens.
* **Smooth scrolling:** Lenis integration with anchor navigation and reduced-motion support.
* **Scroll animations:** Subtle reveal effects as content enters the viewport.
* **Interactive project cards:** Image hover effects and animated elements.
* **Custom visual direction:** Four distinct project concepts featuring locally stored images.
* **Accessible navigation:** Semantic HTML and mobile-friendly navigation.

##  Run Locally

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` using the Live Server extension.
4. Explore the website in your browser.

An internet connection is required to load Google Fonts and the Lenis CDN.
